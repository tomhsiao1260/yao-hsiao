# Claude Code 使用心得

AI 讓程式的撰寫越來越便利，在不同的發展階段裡，最讓我有感的就是：ChatGPT, Cursor 和 Claude Code。

對我來說，每個階段都是個體驗的飛躍。還記得 ChatGPT 剛出沒多久，我會習慣把程式錯誤貼上去詢問，這減輕了對語法細節的困擾。接著是 Cursor 的出現，整合了許多開發上的體驗，做到流暢的大面積更改。再來是 Claude Code，深度掌握龐大的程式碼和自主測試，效果真的讓人驚艷。

感覺每過一個階段，就又離程式碼遠了一點。過去會仔細看每行程式，比較語法差異，但隨著 AI 的改動速度加快，像是去年的 Cursor，有種程式碼在流動的感覺，到了今年的 Claude Code，程式碼已經隱藏在背景，並以飛快的速度被更動著。同時 Github 的程式碼正在以飛快的速度增長，每小時幾千幾萬行的 commit 成為了常態。純手寫的程式被大量的稀釋，或者說有種越來越尊貴且稀有的感覺。

這就像把大腦任務外包給 AI 的感覺。還是會想完成手邊的事，只是效率提高了數倍。還記得剛用 Claude Code 的時候，送出提示詞，呆坐在電腦前等待，突然不知道能做些什麼，有種智商降低的感覺，然後才發現空出的時間能做其他事，才又找回了思考的感覺。隨著 AI 帶來的效率提升，依賴感越來越強，每週的額度用完，會有什麼事都不能做的匱乏感，就像是手機突然壞掉，或是眼鏡突然弄丟的那種感覺。

Claude Code 的開發體驗讓我想起小時候玩遊戲的期待感。你可以想像一些東西，嘗試跟系統互動，快速獲得反饋，有時會獲得意外的驚喜，這是過去的程式開發沒有的體驗。以前想完成一個應用，就像執行高難度的體操那樣，需要充分的熟悉，確保每個環節萬無一失，任何錯誤都將讓應用無法運行。反觀現在只要下一些提示詞，就能很快地獲得想要的效果，而且幾乎不會報錯。

雖然 AI 的使用越來越有種獲得超能力的感覺，但事實是，大家也都在用 AI，競爭其實更激烈了。不過不同群體對 AI 的適應程度其實很廣，以科技圈為例，基礎設施競賽，數百個 agent 同時處理任務已經是常態，相反地，許多長輩們最近才發現 ChatGPT 很厲害，並開始學著怎麼使用。這種在不同群體間產生的時間差，我覺得蠻有趣的，就好像從過去走到未來的感覺。

最後，我想謝謝 Dalufishe 願意給我 token 燒，還有 Claude Code 完成了 Neuroglancer 的底層拆解，這些是一年前幾乎不可能做到的事。
