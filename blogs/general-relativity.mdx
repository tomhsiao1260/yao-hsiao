# 廣義相對論學習心得

最近在學廣義相對論，終於看到愛因斯坦方程式了！回過頭來看也已經走很遠了，於是想寫篇文章整理思緒。所以比起學術討論，這篇更像是分享學習時的感受，以及印象深刻的點。那就開始吧！

## 一般的誤解

想像你乘著一道光旅行，穿越了黑洞的事件視界

啊，講錯，不是那個，應該是這個

想像你在一個四維時空的流形上，那裡光怪陸離，大腦的直覺派不上用場，你完全迷失在了哪裡。此時黎曼遞給你一把名為度規的尺，並耐心地告訴你怎麼使用。雖然適應的過程不是很順暢，但你開始能在時空中行走，建立聯絡，丈量彎曲，也漸漸習慣用張量來看清座標轉換的假象。

經過了漫長的跋涉，在這個廣闊的數學沃土上，愛因斯坦終於找到了回去現實的路，並用一條方程式建立起穩固的橋樑。在那之後，人們的思緒能在幾何與物質間穿梭，並試著回答光線行進和黑洞等等的問題，這就是著名的愛因斯坦方程式：

```
R_{\mu\nu} - \frac{1}{2} g_{\mu\nu} R = \frac{8 \pi \small G}{c^4} T_{\mu\nu}
```

還記得前面那段黑洞的想像嗎？我覺得其實廣義相對論最常有的誤解就是：直接跳過上面那段漫長的跋涉，也就是跳過黎曼幾何，所給出的解釋。這麼做或許對物理直覺有些幫助，但好奇心將無法從那裡繼續的推進下去。

## 容易忽略的點

因為廣義相對論大半時間都在學黎曼幾何，久了會變成一種思考習慣。這是好事，但有時候我會提醒自己一些問題，像是：位置是怎麼確定的？校時是怎麼做到的？事件是怎麼關聯的？因為比起可見的數學符號，這些違反直覺的物理觀念，反而容易在不同情境下被忽略討論，成為了思考的盲區。

另外，我想提一下愛因斯坦在狹義相對論的貢獻，其實當時有不少傑出的物理和數學家，好比說 Lorentz 和 Poincaré，也在想這類問題。但愛因斯坦選擇了完全不同的路線，他首先捨棄了以太的概念，並從 David Hume 的哲學出發，重新審視哪些觀念是沒辦法還原到感官經驗的，這讓他發現了絕對時間並非經驗必然的思考盲點，並確立了時間和空間其實是事件的關係網絡。這樣全新思考框架的發展過程，讓我想起了 Alan Kay 的那句名言：

```
Alan Kay: Point of view is worth 80 IQ points.
```

再來是等效原理，如果你告訴我：自由落下時感受不到重力。我不覺得我會因此獲得什麼深刻的啟發。但愛因斯坦卻能以此出發，去徹底改寫整個重力理論。除了洞察外，我覺得還需要蠻大的毅力和勇氣。好比說，當知道光速是恆定的，他決定重新定義時間，並建立了狹義相對論；當知道力學和電磁學不滿足相對性原理，他決定重新建構它們；當意識到重力理論存在根本性問題，他提出了等效原理，並透過黎曼幾何的幫助，確立了廣義相對論。我不覺得這個過程是理所當然的，但在學習時很容易忘記，忘記這些是需要大量嘗試才可能做到的。

## 學習的困難

對大部分的人而言，廣義相對論的學習門檻是高的，尤其是黎曼幾何的數學基礎。因為物理觀念是全新的，數學操作是全新的，而且有時還需要屏蔽過去熟悉的物理和數學概念，以免彼此互相干擾。這是因為我們所處的時空，在幾何的表達上，時間與空間的貢獻是會相消的，使得我們得用更抽象的方式去處理。

雖然數學讓我們能謹慎的想像，但物理圖像的建立變得更加困難了。你可能會盯著某個張量許久，思考它的幾何或物理意義，並在紙上畫一些幾何圖案。但不論是哪種方式，這些透過數學所得出物理現象，都離我們所處的生活環境非常的遙遠且不直觀。

黎曼幾何就像是給大腦的字母體操，指標的上升和下降，張量的協變與反變，形式的對稱與反對稱，所有的操作都遵循著嚴格的規律，需要經過漫長的熟悉，才能在既有的限制下做出優美的協調。也許比起體操，我更希望它是個遊樂場，一個人人都能隨手參與和嘗試的地方。
